# Windsurf Project

A new project created with Windsurf and connected to GitHub.

## Getting Started

### Prerequisites
- Node.js installed on your machine

### Installation
```bash
npm install
```

### Usage
```bash
npm start
```

## Project Structure

```
windsurf-project/
├── index.js          # Main entry point
├── package.json      # Project dependencies and scripts
├── README.md         # Project documentation
└── .gitignore        # Git ignore file
```
